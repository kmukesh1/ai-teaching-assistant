# AI Teaching Assistant

Production-ready AI Teaching Assistant with Streamlit frontend, FastAPI backend, RAG over PDFs, Quiz/Assignment/Study Plan generators, and multi-LLM support (Gemini, OpenAI, Ollama).

## Quick Deploy to Streamlit Cloud
1. Fork or use this repo
2. Go to share.streamlit.io
3. Deploy with main file: `frontend/streamlit_app.py`
4. Add your GEMINI_API_KEY in Secrets

Built as a complete project for non-technical users.
